## 1. 口径与责任

v2.0本地P0–P8已完成，不代表历版路线图、策略目录及整体愿景全部完成。此前“本地计划无剩余开发项”仅适用于该限定范围，不能用于关闭下列欠项。没有真实账户不阻止本地模拟工程继续开发；供应商权限、自然时间观察、真实下单授权分别处理。

- **未完成工程**：缺完整实现或可验收的端到端链路，不是简单隐藏按钮。
- **部分实现**：已有目录、契约、理论工具或局部流程，不能当完整策略执行。
- **待外部验证**：已有基础实现，但真实来源、实际账单或自然时间证据未完成；不推断剩余适配代码已经写完。
- **后续扩展**：曾被列入建议或目录，记录在此，不等于原GOAL强制验收项，也不自动授予真实交易或购买权限。

以下各项均保持开放，只有实现和对应验收证据齐备才可关闭。历史文档可能记载旧状态，14模板和滚动/Wheel以当前v2.0为准。

## 4. 源码核查锚点与误判防护

- `src/personal_quant/workspace/capital.py`：`PREVIEW_ONLY`及只读账本，不是多策略执行器。
- `src/personal_quant/hedging/sizing.py`：`UNSUPPORTED_SHORT_OR_RESERVED_SHARES` / `UNSUPPORTED_SHORT`，减持不能误算为卖空。
- `src/personal_quant/options/catalog.py`：14类目录与14种月度模板不同，非模板可能只有`STANDARD_LEGS`或`CATALOG_ONLY`；`MONTHLY_RESEARCH`不包含所有目录策略。
- `src/personal_quant/options/selection.py`：非`PHYSICAL`产生`UNSUPPORTED_A8_SETTLEMENT`；合约契约字段存在不等于执行路径支持。
- `src/personal_quant/hedging/catalog.py`：目录`executable=False`；此字段也不意味着所有核心对冲从未实现，需结合具体计划和模拟入口。

本次为计划、矩阵与关键门禁的静态核查，不声称逐一运行了所有未支持组合，也不是全源码无遗漏认证。发现其他缺口继续添加，保留稳定ID；D/V/Q按交付验收关闭，不通过移动到新版或改名消失。

## 1. 范围变更及分层目标

用户追加要求研究期权并纳入v1.9。本版保留原P0–P5可靠性和研究工作，新增O0–O6。期权不是单纯新增ETF权重模板：现有账本按数量×价格计算，缺合约乘数、空头期权义务、指派及交割事件；已有六策略和257项测试不能证明期权正确。

默认先研究**美股ETF标准期权，SPY作为工程样例、USD、一个隔离工作区一个账户**；用户市场偏好未确认。如果改为A股ETF或指数/期货期权，必须替换合约、日历、交割、数据和权限适配后重新验收，不套用美股标准。ETF的XNYS日历不能自动当成所有期权合约的交易日历。

| 层级 | v1.9交付范围 | 成功含义 |
|---|---|---|
| L0 策略目录 | 主流结构、变体、期限标签及专业扩展 | 用户能看见腿结构、条件、风险和支持状态，不代表可回测 |
| L1 情景研究 | 标准香草多腿构建、到期盈亏、期限内理论价值/Greeks及压力图 | 明确scenario_only；非标准/路径依赖合约只列目录 |
| L2 历史研究 | A组8模板的真实历史报价回放及同条件基准；B组按门槛扩展 | 有合格历史链、成熟生命周期引擎、费用及缺口证据 |
| L3 前向模拟/人工执行 | 通过验证的模板接paper及人工计划、实际成交/指派导入、对账 | 实际运行和凭据；无券商自动下单 |

各策略分别维护目录、情景、历史、paper、real计划的状态和证据，不用一个“支持”勾选代替五种能力。没有真实历史数据时L1可交付，L2必须保持受阻；L3不能引用历史重建信号。V2自动交易不因本次期权规划自动启动。

原ETF“只做多”不直接等于期权只能买入：备兑Call和现金担保Put包含期权空头。本次范围明确放宽为**允许经过验证的期权腿方向，禁止融资借款、无担保裸卖及未经批准的标的卖空计划**。期权自带非线性和杠杆效应，不能继续笼统宣传“期权无杠杆”；改用权利金/最大损失/名义额/Delta和履约能力控制。研究中的看跌结构可有负Delta，真实启用仍依据明确配置及账户权限。

## 2. 策略支持顺序

### A组：首批完整研究与生命周期目标

1. **Protective Put**：已有标的+保护Put，先完成购买、估值、平仓、到期和实物行权。
2. **Covered Call**：股份覆盖的卖Call；标的被其他计划占用时不得重复覆盖。
3. **Cash-Secured Put**：足额结算现金支持履约；权利金不是立即实现盈利。
4. **Collar**：持股+保护Put+备兑Call，统一覆盖及预算。
5. **Long Call / Long Put**：两种独立单腿；处理无行权资金/无可交割标的的情况。
6. **Bull Call Debit Spread / Bear Put Debit Spread**：两种借记垂直价差；逐腿指派/行权和资金风险通过后接计划。

以上合计8模板。可以先完成情景和历史，再逐个开放paper/人工建议；闭环尚未通过的模板不得显示READY。优先级属于工程安排，不是对用户资金的策略推荐。

### B组：条件扩展清单

| 批次 | 策略 | 开启门槛 |
|---|---|---|
| B1 | Bull Put / Bear Call信用价差，买跨式/宽跨式 | 多腿同步报价、有限边界证明、指派路径和履约资金通过 |
| B2 | 普通/铁蝶、普通/铁鹰、非对称蝶翼 | 3–4执行价腿、尾部斜率、非等宽风险、部分成交异常通过 |
| B3 | Wheel、滚动保护/备兑/Collar | 基础模板已通过；指派/结算驱动状态转换及滚仓幂等通过 |
| B4 | 正向日历、对角、PMCC、双日历/双对角 | 跨到期估值、远月残值、近月指派、IV期限结构及资金核验 |
| B5 | Backspread、Covered Strangle、Stock Repair、其他有界腿组合 | 不同数量的保护、实际担保、理论与路径风险逐项证明 |

B是已纳入v1.9路线的条件批次，不是已交付或默认真实启用。某批次缺数据/模型时记录具体受阻，不能通过改名“自定义策略”绕过。裸卖、裸跨式、无覆盖比例/反向日历、借券合成及套利进入C级目录/适用情景；0DTE、动态Gamma、dispersion和奇异产品进入D级独立扩展，不列本版可执行验收。

核心工程验收覆盖原P0–P5以及O0–O4的A组、O6；O5为按条件推进的扩展，交付时必须逐项列出状态和未覆盖能力，不能将未实施B组写成已支持。真实接入和F/OF观察仍按独立门槛报告。用户后续明确指定的B组策略应加入当次必交范围，不以“条件扩展”为由省略。

## 3. 开源引擎边界与O0技术验证

调研结论：bt保留现有ETF组合研究；QuantLib评估定价及Greeks；LEAN评估期权生命周期。这是对原框架范围的明确扩展，原因是新增合约与行权/指派，不是引入另一套重叠ETF研究平台。依据及许可证见[调研第4节](V19-OPTIONS-RESEARCH.md)。

- **一次期权/ETF混合研究使用一个引擎**。候选为固定版本的LEAN；同实验ETF基准也在该引擎内运行，不能把bt现金和LEAN头寸拼成组合。
- bt旧报告及研究入口保持兼容，不迁移覆盖历史数值。跨引擎结果仅作差异说明，不能未经校准混成公平策略排名。
- QuantLib仅承担理论定价/IV/Greeks，不伪装成交、历史行情或另一套回测。优先复用选定引擎现成接口，避免并行维护重复模型。
- 研究引擎拥有一次历史模拟的内部状态；真实/paper持久账户仍由LyraX唯一事件账本派生。适配器返回标准化成交/生命周期候选事件，不能另写一份独立真实余额；两边核对不一致则阻断发布。
- O0必须在隔离环境验证：源码/许可、可重复构建、无自动数据采购的本地运行、Python/C#边界、合约数据导入、指派/交割事件导出、实际费用、报告及恢复。
- 官方LEAN CLI有付费组织条件，数据及Docker/.NET路径也需独立验证；不得假设已安装或免费。先验证可行的开源引擎直接运行路径，成功后锁定版本/提交和依赖；不能自动购买平台服务。
- 若成熟引擎无法在现有条件运行，交付L0/L1和适配契约，L2/L3标受阻；不临时重写完整期权回测、指派或撮合引擎。

## 5. 可复现信号、选约及成交

### 5.1 首个工程规格

以SPY标准未调整合约演示，参数在看结果前冻结：月末决策；目标DTE45个自然日、允许30–60日；仅从当时已挂牌合约选择，按距45日绝对差、较早到期及稳定ID依次打破并列。无合约则NO_ELIGIBLE_CONTRACT，不能未来补选。

执行价示例由标的未复权参考价选取：保护Put取不高于0.95×S的最近挂牌K；备兑Call取不低于1.05×S的最近K；现金担保Put示例同0.95×S。单腿/价差各有独立冻结规则，不把示例参数当最优值；数量、预算、费用、流动性阈值和允许模板来自显式配置。首版按moneyness选约，Delta选约需合格且时点正确的Greeks后再开。

到期前7个自然日进入退出检查（落到非交易日时按该合约最后可用交易时点提前安排）；常规增加风险仍仅在月度决策。提前退出/风险暂停属于管理事件，不自动每日补回目标仓位。是否滚仓、何时建立下一期保护必须写入规格，保护空档如实展示。

### 5.2 时间口径

- 月末收盘及数据发布后形成信号，具体合约/数量冻结；成交只能发生在之后的合格交易时点。
- 期权按来源提供的明确快照时点模拟，例如次交易日15:45美东时间；不能一概叫“收盘成交”。标的与期权快照需时间对齐，半日交易使用实际时间，列名1545不代表一定在15:45。
- 选约用决策前数据，未来执行报价仅用于成交检查/记录，不重挑最有利合约或数量。原冻结合约缺价/到期则阻断或按预先规则结束，不事后换腿。
- 历史回放使用推定发布时点必须标重建；paper必须确实在成交前取得数据并冻结计划，迟到EOD文件不能冒充当时成交依据。
- 只支持约定频率的管理，不承诺盘中止损、实时避开指派或0DTE执行。

### 5.3 价格、费用与多腿

- 研究默认买入ask、卖出bid，加明确不利滑点/费用；mid仅作估值或独立敏感性场景，不宣称能成交。
- 每合约、每腿、最低费用、交易所/监管及行权指派费分别配置；不把ETF的bps或可分割虚拟份额直接套到期权。
- 多腿必须有同一时点或限定同步误差的完整报价、数量和保护关系；缺任何必要腿不得制造完整组合成交。逐腿NBBO组合是模拟假设，不等于交易所组合报价或保证同时成交。
- 复用成熟引擎成交接口，不新建复杂撮合。真实部分成交逐腿入账，保留组合不完整状态并复核风险；不能以回测原子成交假设拒绝实际事实。
- 开仓保护依赖和保证金要考虑最坏中间状态；平保护腿时不得留下不被允许的裸空头。滚仓是平旧/开新两组事件，不净额掩盖费用和损益。

## 6. 账户、资金、指派与统一计划

```mermaid
flowchart LR
    A[合约/链/标的/行动的版本快照] --> B[冻结规则与具体合约意图]
    L[唯一账户账本与对账] --> C[现金/股份/保护腿及风险检查]
    B --> C
    C --> D[带依赖的多腿人工计划或模拟计划]
    D --> E[成熟引擎模拟事件或实际凭据]
    E --> F[幂等成交/指派/行权/交割事件]
    F --> L
    L --> G[估值、风险、研究及执行复盘]
```

- 数量为整份合约，合约报价乘数与交割物数量分别存储。开仓买/卖与平仓买/卖明确标记，不能把期权空头当成违规负股票数量后删掉。
- 权益包含带符号的期权市值。卖出权利金增加现金或应收，同时产生空头负债，不能立即计作净利润；保证金/预留只限制购买力，不再次扣权益。
- 标准现金担保Put至少预留K×交割股数及费用/缓冲；一般调整合约按明确行权现金和交割物计算。不能把预期卖出款、未结算资金或另一计划已占用现金当担保。
- 备兑Call按实际可交割且未占用股份覆盖；同一股不能覆盖两个计划。价差的保护腿不能重复抵扣两份空头，也不能仅用理论到期最大损失替代指派期间资金需求。
- 底层ETF策略和期权overlay进入统一组合规划，不各自产生冲突计划。ETF减仓先检查备兑/保护关系；需要平期权才能卖股时形成依赖。Wheel为独立状态策略，不能同时与另一规则争用同一资金。
- 美式提前行权/指派、除息前风险、到期价内未行权或价外被行权的可能性按产品/券商规则处理；不能由到期收盘价单独断定真实指派。实际凭据优先，[OIC行权说明](https://www.optionseducation.org/optionsoverview/exercising-options)供规则核对。
- 模拟使用已锁模型和明确假设，另做提前指派/未指派分支压力测试；框架默认指派模型不是历史真相。模拟到期事件、实际券商事件和研究估计分别标识。
- 真实已发生而违反计划/资金限制的事件不能丢弃：保留凭据，能可靠规范化则记账并产生异常；无法处理交割物时保存待核实并阻断后续，而不是虚构现金结算。
- 实物行权把期权变为标的及现金变化，不能同时再加内在价值收益；现金结算产品须使用正式结算值，AM/PM和最后交易时点不可混用。
- 生命周期至少区分OPEN、PARTIAL_CLOSE、EXERCISE_PENDING、ASSIGNMENT_PENDING、SETTLEMENT_PENDING、CLOSED和RECONCILIATION_REQUIRED；在途义务未核实时不释放担保。
- 新字段/表先定迁移和v4旧记录映射：旧证券乘数1，旧计划原样可读；不自动认领旧股票代码为期权。全量备份、回滚、冲销/更正及重放必须支持。

## 7. 情景、风险和报告

- 多腿到期图从各腿现金流合成。对同到期标准香草组合，检查S≥0的端点、全部执行价拐点及尾部斜率，再判最大损失/收益；图上有限横轴不能把裸卖Call画成有限损失。
- 不同到期组合在近月到期时仍有远月时间价值，展示带IV/利率/分红假设的条件估值曲线；不套同到期内在价值或报未经证明的固定最大损失。
- 美式/欧式、离散分红、利率期限及调整合约选择合适成熟定价模型。模型失效、IV无解或Greeks缺失显示原因，不自动写0。理论结果不能填补真实报价用于交易。
- 汇总Delta/Gamma/Vega/Theta/Rho时显示单位：每份/乘数、每1个波动率百分点/每年或每日、币种等。组合同时看美元Delta、名义额、权利金、担保、期限集中度和压力损失，不只看权重合计。
- 压力情景覆盖标的大幅涨跌/跳空、IV上移、期限前移、报价扩大、提前指派、长腿缺价和资金延迟；阈值来自用户配置，不能保证最大回撤。
- 回测比较用相同总资本、同区间、现金收益、实际单位和费用条件。分别提供现金、裸持ETF或相同底层仓位对照；不拿权利金为分母的收益与全资本ETF收益排名。
- 报告包含标的/期权/现金贡献、权利金现金流与实际损益、费用、换手、覆盖率、缺口、指派/行权、滚仓、最低可用资金和担保占用。保留亏损和缺价区间，不删除后美化年化收益。
- 研究数据类型至少区分payoff_only、scenario_only、historical_quotes_with_modeled_lifecycle、forward_paper、real_account；真实历史报价加假设指派仍是模拟，不能叫真实交易业绩。

## 月度期权模板

以下12种均有选约规则及原生模拟路径。合成样本不作为实际期权行情、权限或前向收益证明。

| template_id | 规则 | 机械/资金路径 |
|---|---|---|
| long_call | 买Call | 成交、费用、平仓/到期/行权 |
| long_put | 买Put | 同上；实物交割需核对股份与资金 |
| protective_put | 持股保护Put | 先有足额股票、买Put、持续持股滚动及退出 |
| covered_call | 备兑Call | 确切股份覆盖、指派交股、覆盖不足暂停 |
| cash_secured_put | 现金担保Put | 全额履约现金、指派接股、结算 |
| collar | 持股+Put−Call | 共用股份覆盖、短腿先退出、自然交割与清理 |
| bull_call_debit_spread | 牛Call借记价差 | 多腿资本、提前指派/中间风险与恢复 |
| bear_put_debit_spread | 熊Put借记价差 | 多腿、实物交割及异常检查 |
| long_straddle | 买跨式 | 两腿买入、费用、平仓与到期交割风险 |
| long_strangle | 买宽跨式 | 不同行权价两腿及上述闭环 |
| bull_put_credit_spread | 牛Put信用价差 | 净信用/宽度、履约资金、指派/保护与退出 |
| bear_call_credit_spread | 熊Call信用价差 | 净信用/宽度、股份交割、保护与中间风险 |

滚动保护/备兑/Collar保留已有股票；新周期先处理旧义务、结算和覆盖。Wheel通过冻结请求/CLI使用账户状态选择CSP或备兑Call，配置向导下拉框仅列上述12模板。

原生分组已验证两周期指派/未指派、部分Put指派、备份恢复、拆股零碎股/费用后暂停、Call/Collar指派后拒绝无覆盖滚动。显式`assignment_scenarios`是合成故障模型，使用LEAN扩展及官方交割计算；该模型不复用普通公共计划资格。失败尝试保留原生凭据，主账本保留最后已核验前缀。

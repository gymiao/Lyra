# v1.8 数据与执行契约

- 数据身份：沿用不可变snapshot_id。价格series_id由来源、类型、单位、标的集合、USD/XNYS、日历资格组成；因子系列按固定来源及定义元数据组成。角色绑定具有revision，价格与因子角色不能互换。
- 文件头：data/series-heads.json提供已验证系列头，SQLite保存发布登记；登记中断后显式data-series可校验补登记。新v4不回退全局latest；旧latest仅用于v2/v3兼容。
- 消费：信号/研究用signal，规划/成交用execution，账户报告/导入预检/对账用valuation；基本面按明确factor绑定。每个信号、计划、报告保存所用快照身份，旧依据不随用途修订而覆盖。
- 更新：网络在发布锁外执行，存储锁内读取/合并/校验/发布。同内容幂等；因子首次收到时点保留。价格与因子损坏的旧目录不能作为新的成功头。
- 迁移：v3→v4新增目录、用途、验证、归档登记和提醒表，不改资金事件；完整备份与源内容复核后事务升级，错误全回滚。高版本拒绝写入。
- 锁顺序：任务/维护锁 → publication_lock → 短SQLite事务。数据直接写入只取publication_lock；research.submit先采集源码、释放发布锁后写DB；research.run计算持research锁，发布再取daily/publication；validation锁包围逐个child；daily持daily锁；backup/迁移持daily/publication；没有SQLite写事务内等待网络或bt。
- 源码：白名单Python源码+四份安装/锁文件。源码内容指纹定位归档，锁内容必须匹配；额外文件拒绝打包。显式研究重算只使用包内代码和输入。所有数值比较的测试在运行前指定check_exact=True，未因结果放宽。
- 套件：规格及子实验在创建时冻结，不改变参数搜索；最多48成员回测、一个本地工作进程、成功项验证后复用、失败项需显式retry，父报告不完整时不伪造整体净值。恢复核实PID及进程身份，不删除存活锁。
- 执行：账本仍为唯一事实。复盘是只读派生结果；费用与相对价差分列，拆股统一单位，冲销按有效事件重放，关闭修订保留历史未完成量。
- 提醒：稳定键去重；确认已读不解除计划或对账阻断，解决与再次发生分别更新状态。

## 14种月度期权模板

共同范围：标准100股、美式、实物交割、单市场USD；依赖当前工具/适配/模板资格与完整链校验。模板存在不赋予真实来源、实盘权限或经纪商保证金条件。

| 模板 | 机械模拟 |
|---|---|
| long_call / long_put | 单腿买入、费用、平仓/到期/交割 |
| protective_put / covered_call / cash_secured_put | 股票保护、股份覆盖、全额担保、指派/结算 |
| collar | 持股+Put−Call；共享覆盖与短腿退出顺序 |
| bull_call_debit_spread / bear_put_debit_spread | 借记价差、逐腿资本/交割风险与恢复 |
| bull_put_credit_spread / bear_call_credit_spread | 信用价差、全额履约资金/保护腿与中间异常 |
| long_straddle / long_strangle | 两腿买入、到期及双边交割风险 |
| iron_condor | OTM短Put/Call、同到期双长翼、净信用为正且小于最大翼宽 |
| iron_butterfly | 同行权价ATM短Put/Call、同到期等宽双长翼及同样信用限制 |

铁鹰/铁蝶先长翼、再短腿；预留短Put全额履约现金及长Call全额行权现金，手续费独立预留，不假设有限风险保证金或未结算权利金可用。短Call指派可能临时形成待恢复交割缺口，记录异常并阻断新增风险，再按已冻结保护路径处理；不得把异常期间标成安全完成。双向指派、部分成交端点、无价值到期、两周期公共计划及持仓中备份恢复均有独立测试。

滚动持股沿用原规则，先清旧义务再开新周期。Wheel后续CSP/备兑Call分支由此前原生前缀事实决定；未结算/覆盖不足阻断，不从未来行情选择分支。

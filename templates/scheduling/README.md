# 本地调度样例

模板未安装。修改绝对工作目录、Conda解释器、账户及本地配置后审阅再安装。每小时检查是为了覆盖美国夏令时和提前收市；daily按交易日历、发布延迟和幂等键决定实际处理。不要为过去日期造信号。`Persistent=false`避免服务恢复时自动触发漏跑。

先在终端执行ExecStart对应命令，核对doctor与账户；服务日志使用`journalctl --user -u lyrax-daily.service`，日志保留策略由本机journald配置管理。WSL需先明确是否启用systemd及会话驻留；休眠/关机不会执行任务，使用运行状态页核对缺口。模板本身不证明调度已安装或长期运行。
